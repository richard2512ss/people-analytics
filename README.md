# People Analytics — Employee Attrition Prediction

A web application that estimates the probability of an employee leaving the company,
built to support HR decision-making. The tool uses a logistic regression model
trained on employee data, allowing HR to explore how different factors — such as
overtime, income, tenure, and job satisfaction — affect the likelihood of attrition.

## Features

- Interactive attrition risk calculator (adjust employee attributes, see probability update live)
- Exploratory data analysis of 29 employee variables (distributions, correlations, significance tests)
- Logistic regression model with interpretable odds ratios
- Simple interface, accessible directly from the browser
